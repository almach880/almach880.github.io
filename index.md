## 💡 Troubleshooting common issues

The application does not open.
Check if your antivirus software blocked the execution. Sometimes security settings prevent new programs from starting. Check your antivirus history to see if it quarantined the file.

The interface looks distorted.
Ensure your monitor scaling is set to 100% or 125% in your Windows display settings. Extremely high scaling settings can sometimes shift elements off the screen.

The text is too small.
Use the keyboard shortcut Ctrl and the + key to zoom in. Use Ctrl and the - key to zoom out. This resets the view to a size that fits your eyes.
